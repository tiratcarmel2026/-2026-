# אתר וורדפרס - עיריית טירת כרמל

תבנית וורדפרס (theme) + תוסף ליבה (plugin) לאתר האינטרנט הרשמי של עיריית טירת
כרמל. העיצוב מבוסס על המוקאפים שסופקו (עמוד בית עם תמונת רקע של העיר, רשת
כרטיסי שירות, רצועת עדכונים, אירועים קרובים, פוטר עם גלים) ועמודים פנימיים
באותו סגנון בדיוק - רק בלי תמונת הרקע הגדולה.

כל התוכן (מכרזים, כתבות, אירועים, כרטיסי שירות, טלפונים, רשתות חברתיות, בוט
הניווט) ניתן לעריכה מלאה מפאנל הניהול (wp-admin) בלי לגעת בקוד.

## מה יש כאן

```
wordpress-site/
  docker-compose.yml              # סביבת פיתוח מקומית (וורדפרס + MySQL + phpMyAdmin)
  wp-content/
    themes/tirat-carmel/          # העיצוב: header/footer/עמוד בית/עמודים פנימיים
    plugins/tirat-carmel-core/    # הלוגיקה: מכרזים, אירועים, כרטיסי שירות, הגדרות, בוט
```

### התבנית (`themes/tirat-carmel`)
- `front-page.php` - עמוד הבית: הירו עם תמונת העיר, 7 כרטיסי שירות, רצועת
  "עדכונים חשובים", "אירועים קרובים".
- `page.php` - כל עמוד פנימי רגיל: אותו הדר/פוטר, כותרת בסרט כחול **ללא**
  תמונת רקע, פירורי לחם, אפשרות לסרגל צד.
- `single.php` / `archive-tender.php` / `single-tender.php` /
  `archive-tc_event.php` / `single-tc_event.php` - תבניות לכתבות, מכרזים
  ואירועים.
- כפתור נגישות (`template-parts/accessibility-widget.php`) ובוט ניווט
  (`template-parts/chatbot-widget.php`) מוזרקים אוטומטית לכל עמוד.
- כל הטקסט קשיח בעברית, RTL מלא, מבוסס על Assistant (גופן עברי מ-Google
  Fonts) עם נפילה חזרה ל-Arial.

### התוסף (`plugins/tirat-carmel-core`)
- **מכרזים** (`tender`) - סוג תוכן עם מספר מכרז, תאריך פרסום, מועד אחרון
  להגשה, סטטוס (פתוח/נסגר בקרוב/סגור - מחושב אוטומטית לפי התאריך), איש קשר,
  וקבצים מצורפים (PDF/Word/Excel/תמונות) מתוך ספריית המדיה.
- **אירועים** (`tc_event`) - תאריך, שעה, מיקום, תמונה, קישור להרשמה.
  מוצגים אוטומטית בעמוד הבית ("אירועים קרובים") ובעמוד אירועים ייעודי.
- **כתבות ועדכונים** - פוסטים רגילים של וורדפרס (Post) - אפשר להעלות בהם
  קבצי PDF/Word ותמונות דרך עורך הבלוקים הרגיל, ובנוסף יש תיבת "קבצים
  מצורפים" ייעודית לצירוף מסודר של קבצים (בדיוק כמו במכרזים).
- **כרטיסי שירות בעמוד הבית** - מסך ניהול ייעודי (`עיריית טירת כרמל > כרטיסי
  שירות`) לעריכת 7 הכרטיסים (חירום, תשלומים, אירועים...), כולל הוספה/מחיקה/
  שינוי סדר, כותרת, תיאור, קישור ואייקון.
- **הגדרות אתר** (`עיריית טירת כרמל > הגדרות`) - טלפון, מייל, כתובת, טקסטים
  בפס ה-106, סלוגן בפוטר, קישורי רשתות חברתיות.
- **בוט ניווט** (`עיריית טירת כרמל > בוט ניווט`) - רשימת "כוונים" (מילות
  מפתח + תשובה + כפתור ניווט) שהבוט הצף באתר משתמש בהן כדי לכוון תושבים
  לעמוד הנכון (מכרזים, תשלומים, אירועים, יצירת קשר, נגישות, חירום...). לא
  תלוי בשירות AI חיצוני בתשלום - הכל רץ מקומית מול ה-REST API של האתר.
- **PWA** - `/manifest.webmanifest` ו-`/sw.js` נוצרים אוטומטית, כדי שהאתר
  יהיה ניתן ל"התקנה" ממסך הבית כבר היום (ראו "אפליקציה נייטיבית" למטה).
- **REST API** - מכרזים, אירועים, כרטיסי שירות והגדרות האתר נחשפים תחת
  `/wp-json/tirat-carmel/v1/...` ותחת ה-REST הרגיל של וורדפרס
  (`/wp-json/wp/v2/tenders`, `/wp-json/wp/v2/events`), כבסיס לאפליקציה
  נייטיבית עתידית.
- **התראות Push (OneSignal)** - הרשמת תושבים להתראות דחיפה בדפדפן/בנייד.
  מוגדר תחת עיריית טירת כרמל > הגדרות > "התראות Push". דורש חשבון חינמי
  ב-[onesignal.com](https://onesignal.com) (App ID, ואופציונלית REST API
  Key לשליחה אוטומטית עם כל פרסום מכרז/אירוע/כתבה חדשים). מפתח ה-REST API
  לעולם לא נחשף בצד הציבורי של האתר. כפתור הרשמה ידני זמין גם בכל מקום
  באתר עם ה-shortcode ‎`[tc_push_subscribe_button]`.
- **באנר חירום** - פס אדום שאפשר להדליק/לכבות בלחיצת כפתור בהגדרות, מוצג
  בראש כל עמודי האתר עם הודעה וקישור לפרטים - להפעלה בזמן אירועי חירום.
- **כפתור וואטסאפ צף** - יצירת קשר מהיר עם מוקד העירייה (מספר נפרד מקישור
  הוואטסאפ שבפוטר).
- **הודעת עוגיות (Cookie consent)** - הודעה בסיסית בתחתית האתר בביקור
  ראשון, ניתנת לכיבוי מהגדרות.
- **נתונים מובנים ל-Google (Schema.org)** - פרטי העירייה (טלפון, כתובת,
  לוגו, רשתות חברתיות) מוצגים למנועי חיפוש בפורמט `GovernmentOrganization`.
- **מחלקות ואנשי קשר** (`department`) - מדריך מחלקות העירייה: שם מנהל/ת,
  טלפון, מייל, שעות קבלת קהל, חדר. עמוד ארכיון עם רשת כרטיסים ועמוד לכל
  מחלקה בנפרד.
- **פרוטוקולים ושקיפות** (`protocol`) - לפרסום פרוטוקולי ישיבות מועצה,
  תקציב, דוחות כספיים ושכר בכירים, כנדרש בחוק חופש המידע לרשויות מקומיות.
  תומך בקבצים מצורפים כמו מכרזים, וסימון סוג המסמך.
- **מפת מקלטים אינטראקטיבית** (`shelter` + ‎`[tc_shelter_map]`) - מפה
  מבוססת [Leaflet.js](https://leafletjs.com) עם אריחי OpenStreetMap,
  **ללא צורך במפתח API או חשבון בתשלום** (בניגוד ל-Google Maps). הספרייה
  ארוזה מקומית בתוסף (`wp-content/plugins/tirat-carmel-core/vendor/leaflet`)
  ולא נטענת משרת חיצוני. לכל מקלט מוזנים קואורדינטות, כתובת, קיבולת
  ונגישות.
- **תבנית עמוד "חירום"** (`template-emergency.php`) - כדי להשתמש בה: יוצרים
  עמוד וורדפרס רגיל (למשל בשם "חירום"), ובתיבת "תבנית עמוד" בסרגל הצד
  בוחרים "עמוד חירום". התבנית מוסיפה אוטומטית, מעבר לתוכן שכותבים בעורך:
  - **רולר עדכוני חירום** - מציג רק פוסטים ששויכו לקטגוריה עם ה-slug
    ‎`emergency` (יוצרים אותה ב-Posts > Categories); אם הקטגוריה לא קיימת
    עדיין, הרולר מציג את העדכונים האחרונים באתר.
  - **מפת מקלטים** - אותה מפה כמו ה-shortcode, מוטמעת אוטומטית.
  - **צביעת העמוד בצבע התראה** - מתחת ל"מצב חירום" בעמוד ההגדרות יש
    צ'קבוקס + בורר צבע; כשמופעל, כותרת עמוד החירום ורכיביו צובעים
    בצבע שנבחר (ברירת מחדל אדום) להדגשה חזותית בזמן אירוע בפועל.

## הרצה מקומית (לבדיקה לפני העלייה לאוויר)

**הערה:** בסביבת הפיתוח שבה נבנה הקוד הזה (sandbox מבודד) אין גישה לאינטרנט
החיצוני, ולכן לא היה ניתן להוריד את קובצי Docker Hub / wordpress.org כדי
להריץ ולצלם את האתר בפועל. כל קובצי ה-PHP נבדקו עם `php -l` (בדיקת תחביר)
ועברו בהצלחה, ובוצעה בדיקה שכל פונקציה שנקראת בקוד אכן מוגדרת - אבל מומלץ
להריץ בדיקה חזותית אצלכם (או לבקש ממני להריץ אותה בסשן עם גישה לאינטרנט)
לפני שמעלים לאוויר.

1. יש להתקין [Docker Desktop](https://www.docker.com/products/docker-desktop/)
   (או Docker + Docker Compose בלינוקס).
2. בתיקיית `wordpress-site`:
   ```bash
   cp .env.example .env
   docker compose up -d
   ```
3. פתחו את `http://localhost:8080` - יופיע מסך התקנת וורדפרס. מלאו שם אתר,
   שם משתמש וסיסמת מנהל.
4. בפאנל הניהול (`http://localhost:8080/wp-admin`):
   - **מראה > תבניות** - הפעילו את "עיריית טירת כרמל".
   - **תוספים** - הפעילו את "Tirat Carmel Core".
   - **הגדרות > קישורים קבועים** - לחצו "שמירת שינויים" פעם אחת (כדי
     שהקישורים למכרזים/אירועים יעבדו).
5. מסך "עיריית טירת כרמל" בתפריט הצד השמאלי הוא נקודת הכניסה לכל ההגדרות.

phpMyAdmin (לניהול בסיס הנתונים) זמין ב-`http://localhost:8081`.

## הגדרה ראשונית לאחר ההתקנה

1. **לוגו ותמונת רקע**: מראה > התאמה אישית > זהות האתר - העלו את לוגו
   העירייה (הקובץ שסיפקתם). את תמונת הרקע של עמוד הבית ניתן להחליף גם היא
   באותו מסך (או ישירות בקוד ב-`front-page.php` דרך `tc_hero_image`).
2. **תפריטים**: מראה > תפריטים - צרו תפריט וסמנו אותו כ"תפריט ראשי", ותפריט
   נוסף שיסומן "מפת אתר בפוטר".
3. **כרטיסי שירות**: עיריית טירת כרמל > כרטיסי שירות - ערכו את 7 הכרטיסים.
4. **מכרזים**: מכרזים > הוספת מכרז חדש - מלאו מספר מכרז, תאריכים, וצרפו
   קבצים.
5. **אירועים**: אירועים > הוספת אירוע חדש.
6. **כתבות/עדכונים**: פוסטים > הוסף חדש - כל פוסט חדש מופיע אוטומטית ברצועת
   "עדכונים חשובים" בעמוד הבית.
7. **בוט הניווט**: עיריית טירת כרמל > בוט ניווט - ערכו/הוסיפו כוונים. יש
   כוונים לדוגמה מוכנים מראש (מכרזים, תשלומים, אירועים, יצירת קשר, נגישות,
   חירום, שעות פתיחה) גם בלי לערוך כלום.
8. **דפים פנימיים**: כל עמוד רגיל (עמוד "אודות", "יצירת קשר" וכו') מקבל
   אוטומטית את אותו הדר/פוטר בדיוק כמו עמוד הבית, בלי תמונת הרקע. בעריכת כל
   עמוד יש תיבה "הגדרות תצוגת העמוד" לכותרת משנה ולהסתרת סרגל צד.

## נגישות (תקן ישראלי 5568 / WCAG 2.0 AA)

כפתור הנגישות הכחול (בפינה) כולל: הגדלה/הקטנה של טקסט, ניגודיות גבוהה, מצב
כהה, גווני אפור, הדגשת קישורים, גופן קריא (ידידותי לדיסלקציה), סמן גדול,
עצירת אנימציות, קו קריאה נע, הדגשת כותרות, ואיפוס כללי. ההגדרות נשמרות
בדפדפן של התושב (localStorage). התבנית גם תומכת ב"דילוג לתוכן הראשי",
ניווט מקלדת מלא, ותוויות ARIA.

**חשוב - הבהרה משפטית**: זהו כלי טכני התומך בנגישות, אך **אינו תחליף** להצהרת
נגישות רשמית ובדיקת נגישות ע"י בודק מוסמך, כנדרש בחוק שוויון זכויות לאנשים
עם מוגבלות ותקנותיו. יש להוסיף עמוד "הצהרת נגישות" עם הפרטים הנדרשים (רמת
תאימות, תאריך בדיקה אחרונה, פרטי רכז הנגישות) ולבצע בדיקה תקופתית מול גורם
מוסמך. יש לעדכן את הקישור לעמוד זה תחת עיריית טירת כרמל > הגדרות.

## אפליקציה נייטיבית (חנויות האפליקציות)

האתר "מוכן" כבר היום ברמת ה-PWA: יש `manifest.webmanifest` ו-Service Worker,
כך שתושב יכול ללחוץ "הוספה למסך הבית" בדפדפן הנייד ולקבל חוויה כמו אפליקציה
(אייקון, מסך פתיחה, עבודה חלקית ללא רשת). לפרסום אמיתי בחנויות (Google Play
/ App Store) יש שתי דרכים מומלצות בהמשך הפרויקט:

1. **עטיפת ה-PWA** בכלי כמו [Capacitor](https://capacitorjs.com/) או
   [Median](https://median.co/) - הכי מהיר, אין צורך לכתוב אפליקציה מחדש,
   המסך שתראו הוא בדיוק אתר הוורדפרס.
2. **אפליקציה נייטיבית מלאה** (React Native / Flutter) שצורכת את ה-REST
   API שכבר חשוף (`/wp-json/tirat-carmel/v1/...`, `/wp-json/wp/v2/tenders`,
   `/wp-json/wp/v2/events`) - מתאים אם רוצים חוויית UI שונה לגמרי מהאתר.

שני המסלולים דורשים חשבון מפתח (Apple Developer / Google Play Console) שאינם
חלק מהעבודה הזו.

## אחסון ודומיין

התבנית והתוסף הם קוד וורדפרס סטנדרטי ועובדים על כל אחסון וורדפרס תומך
PHP 8+ / MySQL 8 (או MariaDB). כדי לחבר את `tirat-carmel.muni.il`:

1. בחרו ספק אחסון (VPS/Managed WordPress) והתקינו עליו וורדפרס.
2. העלו את `wp-content/themes/tirat-carmel` ו-`wp-content/plugins/tirat-carmel-core`
   לאותן תיקיות בשרת (FTP/SFTP, או Git deploy).
3. הפעילו את התבנית והתוסף כמו בהתקנה המקומית.
4. מול מחלקת המחשוב/רשם הדומיינים - הפנו רשומת A (או CNAME) של
   `tirat-carmel.muni.il` לכתובת ה-IP של האחסון, והתקינו תעודת SSL (רוב
   ספקי האחסון עושים זאת אוטומטית עם Let's Encrypt).
5. בהגדרות וורדפרס (`כללי`) עדכנו את כתובת האתר לכתובת הסופית.

## הרשאות קבצים

התוסף כבר מאפשר העלאת PDF, Word (doc/docx), Excel (xls/xlsx) בנוסף לתמונות
הרגילות שוורדפרס תומך בהן כברירת מחדל - גם למכרזים וגם לכתבות, ללא צורך
בהגדרה נוספת.
